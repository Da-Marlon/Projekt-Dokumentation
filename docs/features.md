# Funktionen

Das Homelab besteht aus mehreren Diensten, die mit Docker Compose betrieben werden.

## Version 1

- **Caddy:** Reverse Proxy, der Anfragen an die richtigen Dienste weiterleitet
- **Uptime Kuma:** Überwacht die Dienste und zeigt an, ob sie erreichbar sind
- **Portfolio-Seite:** Eigene Webseite, die über Caddy ausgeliefert wird

## Geplant für Version 2

- **Pi-hole:** DNS-Server, der Werbung und Tracker im Netzwerk blockiert
